# Weather App

A simple weather dashboard built with HTML, CSS, and JavaScript.

## Project structure

- `index.html` - main application markup
- `css/style.css` - app styling
- `js/index.js` - app logic and API requests

## Features

- Search weather by city
- Display temperature, humidity, wind speed, and description
- Show 7-day forecast cards
- Toggle temperature display between Celsius and Fahrenheit

## How to run

1. Open `index.html` in a browser.
2. Enter a city name and click **search**.

## Notes

- The app uses the OpenWeatherMap API and Axios for HTTP requests.
- The current build is static and does not require a server.
